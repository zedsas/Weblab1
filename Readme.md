# Лабораторная работа №3

## План декомпозиции

1. Просмотр макета, анализ требований (1 час)

2. UI-kit / дизайн-система (3 часа)
   2.1 Подобрать и сохранить шрифты/цвета (30 минут)  
   2.2 Подготовить стили для кнопок (основная/альтернативная) (1 час)  
   2.3 Подготовить стили для навигации (меню + иконки) (30 минут)  
   2.4 Подготовить стили для карточек направлений/историй (1 час)

3. Структура HTML (8 часов)
   3.1 Сверстать index.html: header/hero/featured/grid/join/recent/footer (4 часа)  
   3.2 Сверстать blog.html: header/hero/видео/контент/галерея/highlights/disclaimer/join/footer (3 часа)  
   3.3 Проверка семантики и изображений/alt (1 час)

4. Стили CSS (6 часов)
   4.1 Разнести стили по файлам: base/layout/components/grid/forms/backgrounds (1 час)  
   4.2 Настроить сетки и карточки (grid) (2 часа)  
   4.3 Настроить формы и кнопки (forms/components) (1 час)  
   4.4 Фоны секций и размеры блоков (backgrounds) (1 час)  
   4.5 Причесать отступы/типографику (layout/base) (1 час)

5. Адаптив и проверка (3 часа)
   5.1 Адаптив до 480px: меню, split-screen блоки, сетки, изображения, форма (2 часа)  
   5.2 Кроссбраузерная проверка и мелкие правки (1 час)

6. Prettier / единый стиль кода (30 минут)
   6.1 Добавить конфиг и прогнать форматирование html/css (30 минут)

Предположительная оценка времени: ~21.5 часа.
